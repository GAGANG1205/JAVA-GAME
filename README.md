# 🏃‍♂️ Java Running Game

A simple 2D running game built using Java (Swing/JavaFX) where the player continuously runs and must avoid obstacles/enemies to survive. The game is built to practice basic game development concepts in Java.

## 🎮 Game Features

- Player auto-runs across the screen
- Enemies appear at random intervals
- Jump mechanic to avoid obstacles
- Score counter based on time survived
- Game Over screen when collided with enemy
- Basic GUI using Java Swing (or JavaFX)

## 🛠️ Tech Stack

- Java (JDK 8+)
- Java Swing / JavaFX (for GUI)
- Object-Oriented Programming concepts
